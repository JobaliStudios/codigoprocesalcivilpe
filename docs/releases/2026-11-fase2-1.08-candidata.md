## 4. Rendimiento: metodología y límites

No se inventan métricas sin trazas comparables. Registrar en mismo dispositivo (versión Android, modelo, temperatura/red aproximadas) para 1.07 y candidata 1.08, haciendo **5 repeticiones** por caso:

1. Arranque frío: desde tocar ícono hasta Inicio interactivo (distinguir demora del formulario UMP).
2. Primera apertura de Búsqueda tras arrancar la app.
3. Búsqueda de texto «embargo» y «medida cautelar» (desde última tecla hasta resultados visibles).
4. Cambio de filtro «Todos» a «Favoritos» y vuelta al lector.
5. Apertura de un artículo largo, desplazamiento y retorno, observando congelamientos y pérdida de fotogramas.

Obtener evidencia mediante grabación/Android Studio Profiler (CPU, frames y memoria) o `adb shell am start -W` para inicio; este último no sustituye una métrica de pantalla interactiva. No interpretar tiempos de CI/Robolectric como tiempos de un teléfono real. Comparar percentiles/mediana solo con datos reales; **no se dispone de mediciones nuevas dentro de este PR**.
